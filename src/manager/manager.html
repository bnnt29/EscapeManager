Eigenen Token am Gerät festlegen: per USB pio run -e update-auth-token oder über „Geräte-Setup“ (siehe PROTOCOL.md Abschnitt 3); ohne eigenen Token gilt der Standard-Token.

Ohne dieses Token lassen sich Pläne weiterhin lokal bearbeiten, importieren und exportieren, werden aber nicht an Geräte gesendet (siehe PROTOCOL.md Abschnitt 3.1). Es wird nur für diese Browser-Sitzung gespeichert.

Ablaufplan geändert

„Neu laden" verwirft Ihre Änderungen und lädt den aktuellen Stand. „Überschreiben" speichert Ihren Stand über den fremden Stand.

Raum-Konflikt erkannt

Diese Komponenten melden dieselbe Rätsel-ID im selben Raum. Das ist nicht eindeutig - der Ablaufplan dieses Raums kann so nicht wissen, welches Gerät gemeint ist. Bitte den Raum bei einer der Komponenten anpassen (zwei getrennte Räume mit demselben Spiel/derselben Rätsel-ID sind hingegen unproblematisch - genau so kann ein Ersatzgerät ein defektes Original ersetzen, siehe "Rätsel-ID" auf der Gerätedetailseite).
