EscapeManager – Gerät einrichten (USB)

Web Serial wird von diesem Browser nicht unterstützt. Bitte Google Chrome oder Microsoft Edge (Desktop) verwenden und diese Datei lokal oder über http://localhost öffnen (Firefox und Safari kennen Web Serial nicht). Alternative ohne Browser, mit PlatformIO am angeschlossenen Gerät: pio run -e set-wifi (WLAN), pio run -e update-auth-token (Token), pio run -e device-info (Info).

1. Gerät verbinden

Gerät per USB anschließen und andere serielle Monitore (PlatformIO, Arduino IDE) schließen. Nach „Verbinden“ den Port des Geräts auswählen.

Gerätedaten

2. Einstellungen ändern

Alle Felder sind optional: leer = unverändert. Jede Änderung wird im Gerät gespeichert; das Gerät startet danach neu.

Einstellungen 1 bis 32 Bytes (UTF-8), keine Steuerzeichen, nicht mit „EscapeSetup-“ beginnen. Name und Passwort werden immer gemeinsam gespeichert. 8 bis 63 druckbare ASCII-Zeichen. Leer lassen geht nur mit „offenes WLAN“. 8 bis 128 druckbare ASCII-Zeichen ohne Leerzeichen, empfohlen mindestens 20. Alle Manager müssen dasselbe Token verwenden. Gleiche Regeln wie beim Token.
